# AAC Communication Board

אפליקציית תקשורת תומכת וחליפית (AAC), המאפשרת לבחור פרופיל,
להרכיב משפט בעזרת מילים ותמונות ולהשמיע אותו בקול.

האפליקציה מותאמת לתצוגה אופקית ופועלת דרך Expo Go.

> מצב נוכחי (5 בספטמבר 2026): הפרויקט שודרג בהדרגה ל־Expo SDK 57. סהר אישר שהאפליקציה עובדת ותקינה לאחר בדיקה באייפון ותיקוני הניקוד, העלאת התמונות וכפתור החיזוי, ואישר מיזוג ל־main.

## יכולות עיקריות

- יצירה, עריכה ומחיקה של פרופילים עם תמונה אופציונלית
- לוח תקשורת קבוע של 3 שורות ו־8 עמודות
- כרטיסי תוכן וכרטיסי ניווט
- יצירת לוחות־בן
- עריכת טקסט ותמונה בכרטיסים
- הוספת ניקוד ידני לטקסט שמוקרא
- בחירת תמונה מהגלריה או צילום במצלמה
- הרכבת משפט והשמעתו בעברית
- חיזוי אישי של המילה הבאה באמצעות Trigram ו־Bigram
- שמירת היסטוריית המשפטים שהושמעו לכל פרופיל
- מצב עורך מוגן בקוד PIN לניהול הפרופילים והכרטיסים

## הרצה

פתח שני חלונות מסוף בתיקיית הפרויקט.

בחלון הראשון הפעל את השרת:
```powershell
dotnet run --project server/AacApi/AacApi/AacApi.csproj --launch-profile http
```

בחלון השני הפעל את הלקוח:
```powershell
npm start
```

סרוק את ה־QR באייפון. המחשב והטלפון צריכים להיות באותה רשת Wi-Fi ומחוברים לחשבון Expo ב־CLI וב־Expo Go.

ההפעלה מעדכנת אוטומטית את כתובת ה־API ב־`.env.local` ומגדירה `EXPO_PUBLIC_USE_RN_FETCH=1` לתמיכה בהעלאת תמונות. לאחר שינוי משתני סביבה הפעל מחדש באמצעות `npm start -- --clear`.

קובצי סביבה מקומיים, תמונות שהועלו וקובצי בנייה אינם נשמרים ב־Git. הנתונים נשמרים ב־SQL Server המקומי; אין SQLite ואין צורך לאפס את המסד לצורך הרצה.
